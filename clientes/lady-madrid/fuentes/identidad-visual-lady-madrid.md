# Identidad Visual Lady Madrid — resumen para diseño

*Fuente: `Identidad Visual Lady Madrid_V3.pdf` (Google Drive, Brand Guidelines
reales de Lady Madrid). Se usa para dar formato al PowerPoint de Hospitalidad
y Cultura de Servicio y a cualquier otro entregable visual del cliente.*

## Logotipo

Tipografía bold en caja alta, altura de "x" reducida, esquinas suaves,
terminaciones especiales (la "Y" recuerda a tipografías monoespaciadas).
Versión en B/N funciona bien con tracking reducido. Hay versión en dos
líneas para espacios reducidos (tarjetas, packaging, perfil de redes).

Tagline real de marca: **"Specialty Coffee Roasters"**.
Dirección real (Plaza República Dominicana): *Pl. Rep. Dominicana 3, Madrid*.

*(No se ha extraído el archivo gráfico del logotipo en sí — este resumen es
texto. Para el PowerPoint se usa un tratamiento tipográfico de "LADY MADRID"
en caja alta, bold, coherente con la descripción — no el logotipo real
vectorizado. Si Andrea tiene el archivo del logo, se puede sustituir.)*

## Color

Paleta primaria real:

| Nombre | Hex | Uso real observado en el brand book |
|---|---|---|
| **Booble Blue** | `#1D79ED` | Color principal en aplicaciones reales (tarjetas, firma digital, folletos) — contraste con el cream tone |
| **Coffee Cream Tone** | `#E7DCCC` | Fondo cálido que acompaña a Booble Blue en casi todas las aplicaciones reales |
| **Moka Orange** | `#E84E27` | Acento energético (bolsas de café de origen) |
| **Sky Pink** | `#ED9ED0` | Acento secundario |
| **Flat Cloudy** | `#3E3D40` | Neutro oscuro — texto, logotipo en oscuro |

Para el PowerPoint: Booble Blue como color dominante (60-70%), Coffee Cream
Tone como fondo cálido de apoyo, Flat Cloudy para texto de cuerpo, Moka
Orange como acento puntual (citas, cifras destacadas, el mantra). Sky Pink se
reserva para un detalle puntual, no como color estructural.

## Tipografía

- **GT Alpina** (títulares) / **GT Alpina Condensed Light** (entradillas,
  subtítulos, destacados, cartelería) — elegante, distinguida, legible.
- **PT Mono** (texto general, párrafos, información formal) — monoespaciada
  con remates, carácter editorial.
- Jerarquía real usada por la marca: Titular GT Alpina 90pt / Entradilla GT
  Alpina Cond Light 35pt / Párrafo PT Mono 18pt.

*(Nota técnica: ninguna de las dos es una fuente "segura" para QA en este
entorno — LibreOffice la sustituirá por otra al renderizar la vista previa.
Se usan igualmente por ser la tipografía real de marca, dejando margen de
holgura en los contenedores de texto para absorber la diferencia de ancho.)*

## Carta real (referencia, no para este documento pero útil como contexto)

La carta de bebidas y comida reales de Lady Madrid está en la página 51 del
brand book (precios y productos reales) — café de especialidad con
escalones de precio, bagels, ensaladas. No se usa en este documento de
Hospitalidad y Cultura, pero confirma el posicionamiento de "especialidad,
cuidado, sin ser pretencioso" ya reflejado en el documento de Estrategia.
